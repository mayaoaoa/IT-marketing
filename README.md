# Weddie

**Weddie** — B2C-платформа для самостоятельной организации свадьбы. 

Пары находят подрядчиков (фотографы, ведущие, флористы, кейтеринг, площадки) с реальными ценами,
портфолио и свободными датами и бронируют их напрямую, без организатора и лишних звонков.

**Что сделано:**
- Сегментация ЦА и ценностные предложения для каждой стороны
- MVP и функциональность
- User Story, Job Story, Job Statement и анализ 4 сил прогресса (JTBD)
- Исследование рынка: TAM / SAM / SOM, анализ конкурентов, карты восприятия и свойств
- Бизнес-модель: комиссия с брони, платное размещение и продвижение
- Коммуникационная стратегия: каскад целей, каналы, бюджет на 3 месяца
- Подготовка и дизайн презентации

**Навыки:** продуктовый менеджмент, JTBD, исследование рынка, бизнес-моделирование, маркетинговая стратегия, визуализация данных и презентация
